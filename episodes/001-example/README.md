# Example episode

A real episode, kept as the format reference. `script.txt` and `episode.json` are the only two
files you write by hand; everything under `audio/` is produced by the pipeline.

The pipeline skips this directory. Episode directories are `NNN` — a name that is not a number
is documentation, so nothing here is numbered over, narrated, rendered onto the page or
published. It is also the one thing under `episodes/` that the repository tracks.

To hear it, copy it to `episodes/001/` and run the production steps from `CLAUDE.md`.
